# Assignment 3: Employee Directory & Management Portal

A modern, responsive React application managing an agricultural enterprise employee directory using React state, synthetic events, modals, and LocalStorage persistence.

---

## 📌 Features & Highlights

- **Full CRUD Management**: Add, View, Edit, and Delete employee records with instant UI updates.
- **Dynamic Search & Filtering**: Real-time filtering by employee name, role, and department.
- **Modal Workflows**:
  - Employee Details modal
  - Add & Edit Employee Form modal with validation
  - Safe Delete confirmation modal
- **State Persistence**: Preserves directory data in browser `localStorage`.
- **Modern UI & Themes**: Dark/Light mode toggle, sleek glassmorphism, responsive cards, and Lucide icons.
- **Zero Config GitHub Pages Deployment**: Pre-configured with GitHub Actions CI/CD.

---

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Lucide React Icons**
- **CSS3 Variables & Flexbox/Grid**

---

## ⚡ Getting Started Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
